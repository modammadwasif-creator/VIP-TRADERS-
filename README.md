## ➕ How to Add Products

1. Open `products-data.js`.
2. Find the `VIP_PRODUCTS` array.
3. Copy an existing product object.
4. Paste it inside the array.
5. Give the new product a unique ID.
6. Update its name, category, price and image.
7. Save the file.

### Example Product

{
    id: "watch-002",
    name: "Luxury Black Watch",
    category: "Watches",
    price: 1500,
    oldPrice: 2000,
    images: [
        "YOUR-IMAGE-LINK"
    ],
    description: "Premium stylish wrist watch.",
    badge: "New Arrival",
    featured: true,
    inStock: true
}

**Important:** Every product must have a unique ID.

## 🚀 Deployment

This project can be hosted free using GitHub Pages.

1. Create a GitHub repository.
2. Upload all project files.
3. Open repository Settings.
4. Select Pages.
5. Choose Deploy from a branch.
6. Select the `main` branch.
7. Select `/ (root)`.
8. Click Save.

Your website will be published through GitHub Pages.
